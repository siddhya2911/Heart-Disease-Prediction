# ❤️ Heart Disease Prediction App

This project is a machine learning web application built using Streamlit that predicts the risk of heart disease based on user input.

---

## 📊 Project Workflow

### 🔍 Exploratory Data Analysis (EDA)

* Checked dataset structure and data types
* Handled missing values
* Analyzed feature distributions
* Visualized correlations between features
* Identified important variables affecting heart disease

---

### 🧠 Feature Engineering / Extraction

* Converted categorical variables using one-hot encoding
* Selected relevant features for better model performance
* Removed unnecessary or redundant columns

---

### ⚙️ Data Preprocessing

* Scaled numerical features using StandardScaler
* Ensured consistent feature format using saved column list
* Prepared data for machine learning model

---

### 🤖 Model Building

* Algorithm used: K-Nearest Neighbors (KNN)
* Trained on processed dataset
* Saved model using joblib

---

### 🌐 Deployment

* Built interactive UI using Streamlit
* Takes user input and predicts heart disease risk in real time

---

## 🚀 Features

* User-friendly interface
* Real-time prediction
* Uses trained ML model
* Handles categorical and numerical data

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit

---

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   streamlit run app.py
